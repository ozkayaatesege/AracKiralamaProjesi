# 🚗 Araç Kiralama Otomasyonu (Car Rental System)

Java ile geliştirilmiş, Nesne Yönelimli Programlama (OOP) prensiplerine uygun bir araç kiralama konsol uygulamasıdır.

## 🌟 Özellikler
* **OOP Mimarisi:** Interface, Abstract Class, Polymorphism ve Inheritance kullanımı.
* **Veri Kalıcılığı:** Araç verileri `cars.txt` dosyasında, kiralama geçmişi `kiralama_gecmisi.txt` dosyasında tutulur.
* **Yönetici Paneli:** Şifreli giriş ile araç ekleme ve silme.
* **Dinamik Fiyatlandırma:** * Elektrikli araçlarda %20 indirim.
    * 7 gün ve üzeri kiralamalarda ekstra %10 "Uzun Dönem" indirimi.
* **Loglama:** Her işlemin tarih ve saat ile kayıt altına alınması.
* **Unit Test:** JUnit 5 ile kritik iş mantıklarının (Fiyat, Stok, Ödeme) test edilmesi.

## 🛠️ Teknolojiler
* Java SE (JDK 17+)
* JUnit 5
* File I/O (Dosya İşlemleri)

## 🚀 Kurulum
1. Projeyi klonlayın.
2. IDE'nizde (Eclipse/IntelliJ) açın.
3. `Main.java` dosyasını çalıştırın.
